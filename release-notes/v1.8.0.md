## v1.8.0 - Dedicated admin folder duplication

Super admins can preview and submit large folder-to-collection duplications from the Mediagraph CLI using separate admin processing capacity.

### Changes

- New `duplicate_storage_folder_to_collection` command previews resolved targets, asset and folder counts, destination conflicts, and worker availability by default.
- Submit with `--execute` and a stable `--idempotency_key`. Reusing the key returns the existing job instead of creating another duplication.
- Follow work with `--wait` or `watch bulk_job <guid>`, and cancel through `cancel_bulk_job`.
- Bulk-job watch and wait now follow retryable errors and use the job GUID for polling.

The command requires a current super-admin account, an active membership in the selected organization, explicit bulk-job write token permission, and configured dedicated admin capacity. It never deletes or replaces destination content.

### Update

```sh
npm install -g @mediagraph/cli@1.8.0
mediagraph duplicate_storage_folder_to_collection --source 123 --destination 456 --preview
```

The accompanying Rails release provides the server-side authorization, duplicate-request protection, and dedicated worker routing.
