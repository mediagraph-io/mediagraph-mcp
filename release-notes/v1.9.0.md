## Transfer share link ownership

Account admins can find eligible new owners and transfer an existing share link through MCP or the CLI. The existing URL and settings carry over. Guest viewing and downloads use the new owner’s permissions.

- Use `list_share_link_owner_candidates` to search eligible account members.
- Use `transfer_share_link_ownership` with the link ID, the new owner’s user ID, and the current owner’s user ID.
- A Lightbox share link can be transferred to an active account member who already belongs to that Lightbox.
