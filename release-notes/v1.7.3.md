## v1.7.3 - Agent attribution and history filtering

CLI and MCP activity now identifies its source automatically, making agent changes easier to find in Mediagraph History.

### Changes

- CLI requests send `X-Mediagraph-Source: cli`; MCP requests send `X-Mediagraph-Source: mcp`.
- The upload signing request carries the same source header. Direct uploads to signed storage URLs keep their existing headers.
- `get_asset_event_log` accepts `request_source` to filter history by `web`, `api`, `mcp`, `cli`, `system`, `agent`, or `unknown`. The `agent` filter includes CLI and MCP activity.

### Mediagraph History

The accompanying Mediagraph release preserves request sources through background jobs and shows Agent badges and source filters in History panels. Older unattributed entries remain available through the Unknown filter.

### Update

```bash
npm install -g @mediagraph/cli@1.7.3
```

The GitHub release also includes the updated MCP desktop bundle.
